# 🧩 팀워크 메이커

모둠활동에서 **일부만 참여하거나 역할이 한쪽으로 쏠리는 문제**를 해결하는 게임형 웹앱이에요.
YES/NO 성향 테스트로 역할을 찾고 → 성향이 골고루 섞이게 팀을 편성하고 → 역할별 할 일이 정해진 협력 미션을 팀 전원이 완료해서 ⭐을 모아요.

`index.html` 파일 하나로 동작해요.

---

## 🎭 모둠 역할 6가지

| 역할 | 하는 일 | 딱 3가지 할 일 |
|---|---|---|
| 🧭 **타임 선장** | 진행·시간 관리 | 할 일 순서 말하기 / 남은 시간 알려주기 / 말 안 한 친구에게 차례 넘기기 |
| 🎤 **무대 장인** | 발표 | 1번 소리 내어 연습 / 팀 대표로 발표 / 질문은 알맞은 팀원에게 연결 |
| 🔍 **자료 탐정** | 자료 조사·준비 | 믿을 만한 자료 2개 / 출처 메모 / 팀에 1분 브리핑 |
| 💡 **아이디어 연금술사** | 아이디어 정리·기록 | 의견 빠짐없이 메모 / 핵심 3줄 정리 / 최종 결정 읽어주기 |
| 🎨 **금손 디자이너** | 시각화·결과물 제작 | 레이아웃 정하기 / 제목·그림·도표 꾸미기 / 그릴 부분 나눠주기 |
| 🔋 **에너지 충전기** | 준비물·응원·마무리 | 준비물 챙기기 / 리액션·칭찬 1번 이상 / 체크리스트 확인 & 뒷정리 |

> 🔋 **에너지 충전기 = 무임승차 성향 학생을 위한 '참여 시동' 역할**이에요.
> 학생 화면에는 "분위기 메이커"로만 보이고, 부담이 낮지만 **안 하면 바로 티가 나는** 일(준비물·리액션·체크리스트)로 0 → 1 참여를 만들어요.
> 협력 미션에서도 이 역할에 꼭 개인 과제가 있고, **팀 전원이 체크해야 ⭐**이라 팀원들이 자연스럽게 챙기게 돼요.

## 🔮 성향 테스트 (교사용 채점표)

질문 8개, YES/NO에 따라 점수가 들어가는 역할이 달라요. 역할마다 받을 수 있는 최대 점수로 나눠(정규화) 공정하게 비교하고, 동점이면 랜덤이에요.

| # | 질문 | YES | NO |
|---|---|---|---|
| 1 | 친구들 앞에서 말할 때 생각보다 별로 안 떨린다 | 🎤+3 🧭+1 | 🔍+1 🎨+1 💡+1 |
| 2 | 궁금한 게 생기면 바로 검색창부터 연다 | 🔍+3 | 🔋+1 🎤+1 |
| 3 | 필기할 때 색깔 펜·그림으로 꾸미는 게 재밌다 | 🎨+3 | 🧭+1 🔍+1 |
| 4 | 대화가 산으로 가면 "자, 정리하면~" 하고 싶다 | 💡+3 🧭+1 | 🔋+1 🎨+1 |
| 5 | 숙제 마감·약속 시간은 미리 챙긴다 | 🧭+3 | 💡+1 🔋+1 |
| 6 | 솔직히 모둠활동은 조용히 따라가는 게 편하다 | 🔋+3 | 🎤+1 🧭+1 |
| 7 | 친구가 잘하면 "오 대박!" 리액션이 먼저 나온다 | 🔋+2 🎤+1 | 🔍+1 💡+1 |
| 8 | 엉뚱한 아이디어가 갑자기 번뜩일 때가 많다 | 💡+2 🎨+1 | 🔍+1 🧭+1 |

## 🧮 팀 편성 방식
1. 같은 성향끼리 몰리지 않게, **인원이 가장 적은 팀 → 같은 성향이 적은 팀** 순서로 한 명씩 배치 (팀 인원 차이 최대 1명)
2. 팀 안에서는 **역할이 겹치지 않도록**, 팀원들의 성향 점수 합이 최대가 되는 조합을 찾아 역할 배정
   (1순위 역할이 겹치면 두 번째로 잘 맞는 역할을 맡아요. 학생 화면에 "능력 개발 찬스" 안내가 떠요)
3. 교사는 **드래그**로 팀 이동, **드롭다운**으로 역할 변경, **🔄 역할 자동 재배치**로 다시 정리 가능

## 🏫 수업 흐름

1. **교사**: 주소 뒤에 `#admin` (또는 첫 화면 "선생님 입장") → 비밀번호 **1107** → **＋ 새 반**
2. **학생**: QR/주소로 접속 → 반 선택 → 번호·이름 → 8문항 테스트 → 내 역할 성향 확인 후 대기
3. **교사 ② 팀 편성**: 팀 수 정하기 → **🎲 팀 배정** → 드래그로 수정 → **👀 학생에게 공개**
   → 모든 학생 화면에서 3·2·1 카운트다운 후 동시에 팀 공개 🎉
4. **교사 ③ 협력 미션**: **전체 팀 미션 뽑기** → 팀마다 다른 미션 1개가 학생 화면에 슬롯처럼 떠요

### 🎯 협력 미션은 이렇게 진행돼요
| 단계 | 누가 | 무엇을 |
|---|---|---|
| ① 뽑기 | 교사 | 미션을 뽑아요 (팀마다 다른 미션 1개). 학생이 직접 뽑지 않아요 |
| ② 각자 내 몫 | 학생 전원 | 미션은 **팀이 함께 1개를 완성**해요. 역할마다 맡은 몫이 달라요<br>예) 협력 인증샷: 사진은 1장! 선장=타이밍, 디자이너=구도, 충전기=촬영…<br>자기 몫을 하고 **'내 몫을 했어요'** 클릭 |
| ③ 팀 인증 | 팀에서 1명 | 팀원 **모두** 완료하면 인증란이 열려요. 무엇을 했는지 쓰고 **선생님께 확인 요청** |
| ④ 확인 | 교사 | '확인 대기' 팀의 결과물을 직접 보고 인증 글을 확인 → **승인(별 +1)** 또는 **다시 하기**(한마디 전달) |
| ⑤ 반복 | 교사 | 다음 미션을 또 뽑아요. 미션은 여러 번(최대 12종) 이어서 할 수 있어요 |

- **별 모으기**: 선생님이 승인한 미션 1개 = 별 1개 (+ 교사 보너스 별)
- **팀 등급**: 별이 쌓이면 🪵 나무 → 🪨 돌 → ⛓️ 철 → 🥇 금 → 💎 다이아 등급
- **반 공동 목표**: 모든 팀 별의 합이 목표(기본 10개)에 닿으면 보상 상자 열림
- 팀에 없는 역할의 몫은 학생 화면에 "빈 역할 · 다 같이!"로 표시돼요
- 교사는 학생 이름 칩을 눌러 대신 체크할 수도 있어요 (기기가 없는 학생 등)

💡 `가상 학생 추가(연습용)` 버튼으로 수업 전에 팀 편성을 미리 연습해 볼 수 있어요.

## 🔌 실제 수업용 설정 (Firebase)

설정 전에는 **데모 모드**예요. 같은 브라우저의 탭끼리만 연결되니 혼자 미리보기용으로 쓰세요.
학생들이 **각자 휴대폰·태블릿·크롬북**에서 접속하려면 Firebase Realtime Database를 연결해야 해요.
(무료 Spark 요금제로 한 반 수업은 충분할 거예요. 요금·한도는 **확인 필요**)

### 1단계. Firebase 프로젝트 만들기
1. [Firebase 콘솔](https://console.firebase.google.com) 접속 → 구글 로그인 → **프로젝트 추가** (이름 예: `teamwork-maker`)
2. Google 애널리틱스는 **사용 안 함**으로 꺼도 돼요

### 2단계. Realtime Database 만들기
1. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**
2. 위치: **싱가포르(asia-southeast1)** 권장 → **잠금 모드로 시작** 선택 → 사용 설정
3. 상단 **규칙** 탭에 아래를 그대로 붙여 넣고 **게시**

```json
{
  "rules": {
    "teamMaker": { ".read": true, ".write": true },
    ".read": false, ".write": false
  }
}
```

### 3단계. 웹 앱 등록하고 설정값 복사
1. 왼쪽 위 **⚙️ → 프로젝트 설정 → 일반** → 아래 '내 앱'에서 **웹(</>)** 아이콘 클릭
2. 앱 닉네임 입력 → **앱 등록** (Firebase 호스팅 체크는 안 해도 돼요)
3. 화면에 나오는 `const firebaseConfig = { ... }` 안의 값을 복사
4. `index.html` 위쪽의 `const FIREBASE_CONFIG = { ... }` 칸에 붙여 넣기
   - **`databaseURL`이 꼭 있어야 해요.** 없으면 Realtime Database 화면 상단의 주소(`https://...firebasedatabase.app`)를 직접 넣어 주세요
5. 저장 후 접속하면 관리자 화면 상단이 **"실시간 연결"**로 바뀌어요 (데모 모드 띠가 사라짐)

### 4단계. 인터넷 주소로 올리기 (어떤 기기에서도 접속)
- **GitHub Pages**: 이 저장소 **Settings → Pages → Branch(브랜치) 선택 → Save**
  → 몇 분 뒤 `https://<아이디>.github.io/team_maker/` 주소가 생겨요
- 또는 [Netlify Drop](https://app.netlify.com/drop)에 **`index.html`과 `fonts` 폴더를 함께** 끌어다 놓기
- 학생 주소: 관리자 화면 ① 탭의 **QR 코드**를 TV·전자칠판에 띄우면 끝!

### 📱 기기 호환
- 휴대폰(360px~)·태블릿·크롬북·PC·전자칠판 모두 한 화면 폭에 맞춰져요 (가로 스크롤 없음)
- 팀 편성 드래그는 마우스와 **터치** 모두 돼요 (전자칠판 OK)
- 학생 기기는 입장 정보를 기억해서, 새로고침하거나 다시 열어도 이어서 진행돼요
- 크롬·사파리·웨일·엣지 최신 버전 권장

### ⚠️ 알아두기
- 관리자 비밀번호(1107)는 화면 잠금 수준이에요. 코드를 열면 보이니 개인정보(실명 전체 등)는 최소로 입력하세요. 수업이 끝나면 **🧹 이 반 기록 초기화** 또는 **🗑 반 삭제**를 눌러 주세요.
