# 🧩 팀워크 메이커

모둠활동에서 **일부만 참여하거나 역할이 한쪽으로 쏠리는 문제**를 해결하는 게임형 웹앱이에요.
YES/NO 성향 테스트로 역할을 찾고 → 성향이 골고루 섞이게 팀을 편성하고 → 역할별 할 일이 정해진 협력 미션을 팀 전원이 완료해서 ⭐을 모아요.

`index.html` 파일 하나로 동작해요.

---

## 🎭 모둠 역할 6가지

| 역할 | 하는 일 | 딱 3가지 할 일 |
|---|---|---|
| 🧭 **타임 선장** | 진행·시간 관리 | 할 일 순서 말하기 / 남은 시간 알려주기 / 말 안 한 친구에게 차례 넘기기 |
| 🎤 **무대 장인** | 발표 | 1번 소리 내어 연습 / 팀 대표로 발표 / 질문은 알맞은 팀원에게 연결 |
| 🔍 **자료 탐정** | 자료 조사·준비 | 믿을 만한 자료 2개 / 출처 메모 / 팀에 1분 브리핑 |
| 💡 **아이디어 연금술사** | 아이디어 정리·기록 | 의견 빠짐없이 메모 / 핵심 3줄 정리 / 최종 결정 읽어주기 |
| 🎨 **금손 디자이너** | 시각화·결과물 제작 | 레이아웃 정하기 / 제목·그림·도표 꾸미기 / 그릴 부분 나눠주기 |
| 🔋 **에너지 충전기** | 준비물·응원·마무리 | 준비물 챙기기 / 리액션·칭찬 1번 이상 / 체크리스트 확인 & 뒷정리 |

> 🔋 **에너지 충전기 = 무임승차 성향 학생을 위한 '참여 시동' 역할**이에요.
> 학생 화면에는 "분위기 메이커"로만 보이고, 부담이 낮지만 **안 하면 바로 티가 나는** 일(준비물·리액션·체크리스트)로 0 → 1 참여를 만들어요.
> 협력 미션에서도 이 역할에 꼭 개인 과제가 있고, **팀 전원이 체크해야 ⭐**이라 팀원들이 자연스럽게 챙기게 돼요.

## 🔮 성향 테스트 (교사용 채점표)

질문 8개, YES/NO에 따라 점수가 들어가는 역할이 달라요. 역할마다 받을 수 있는 최대 점수로 나눠(정규화) 공정하게 비교하고, 동점이면 랜덤이에요.

| # | 질문 | YES | NO |
|---|---|---|---|
| 1 | 친구들 앞에서 말할 때 생각보다 별로 안 떨린다 | 🎤+3 🧭+1 | 🔍+1 🎨+1 💡+1 |
| 2 | 궁금한 게 생기면 바로 검색창부터 연다 | 🔍+3 | 🔋+1 🎤+1 |
| 3 | 필기할 때 색깔 펜·그림으로 꾸미는 게 재밌다 | 🎨+3 | 🧭+1 🔍+1 |
| 4 | 대화가 산으로 가면 "자, 정리하면~" 하고 싶다 | 💡+3 🧭+1 | 🔋+1 🎨+1 |
| 5 | 숙제 마감·약속 시간은 미리 챙긴다 | 🧭+3 | 💡+1 🔋+1 |
| 6 | 솔직히 모둠활동은 조용히 따라가는 게 편하다 | 🔋+3 | 🎤+1 🧭+1 |
| 7 | 친구가 잘하면 "오 대박!" 리액션이 먼저 나온다 | 🔋+2 🎤+1 | 🔍+1 💡+1 |
| 8 | 엉뚱한 아이디어가 갑자기 번뜩일 때가 많다 | 💡+2 🎨+1 | 🔍+1 🧭+1 |

## 🧮 팀 편성 방식
1. 같은 성향끼리 몰리지 않게, **인원이 가장 적은 팀 → 같은 성향이 적은 팀** 순서로 한 명씩 배치 (팀 인원 차이 최대 1명)
2. 팀 안에서는 **역할이 겹치지 않도록**, 팀원들의 성향 점수 합이 최대가 되는 조합을 찾아 역할 배정
   (1순위 역할이 겹치면 두 번째로 잘 맞는 역할을 맡아요. 학생 화면에 "능력 개발 찬스" 안내가 떠요)
3. 교사는 **드래그**로 팀 이동, **드롭다운**으로 역할 변경, **🔄 역할 자동 재배치**로 다시 정리 가능

## 🏫 수업 흐름

1. **교사**: 주소 뒤에 `#admin` (또는 첫 화면 "선생님 입장") → 비밀번호 **1107** → **＋ 새 반**
2. **학생**: QR/주소로 접속 → 반 선택 → 번호·이름 → 8문항 테스트 → 내 역할 성향 확인 후 대기
3. **교사 ② 팀 편성**: 팀 수 정하기 → **🎲 팀 배정** → 드래그로 수정 → **👀 학생에게 공개**
   → 모든 학생 화면에서 3·2·1 카운트다운 후 동시에 팀 공개 🎉
4. **교사 ③ 협력 미션**: **🎲 전체 팀 미션 뽑기** → 팀마다 다른 미션이 슬롯처럼 뽑혀요
5. **학생**: 내 역할의 미션을 하고 **🙌 내 미션 완료!** → 팀원 **모두** 완료하면 ⭐ +1, 팀 캐릭터 진화
   (🥚 → 🐣 → 🐥 → 🦅 → 🐉), 반 전체 ⭐ 합계로 **우리 반 공동 목표** 달성!
6. 교사는 미션 칩을 눌러 대신 체크하거나, ⭐+1 보너스를 줄 수 있어요

💡 `🤖 가상 학생 추가(연습용)` 버튼으로 수업 전에 팀 편성을 미리 연습해 볼 수 있어요.

## 🔌 실제 수업용 설정 (Firebase, 무료 요금제로 충분 — 요금 정책은 확인 필요)

설정 전에는 **데모 모드**예요. 같은 브라우저의 탭끼리만 연결되니 혼자 미리보기용으로 쓰세요.
학생들 각자 기기에서 쓰려면 Firebase Realtime Database를 연결해야 해요.

1. [Firebase 콘솔](https://console.firebase.google.com) → **프로젝트 추가**
2. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기** (위치: 아시아 권장, **테스트 모드로 시작**)
3. **프로젝트 설정(⚙️) → 일반 → 내 앱 → 웹(</>) 앱 추가** → 나오는 `firebaseConfig` 값 복사
4. `index.html`에서 `const FIREBASE_CONFIG = { ... }` 부분에 붙여 넣기 (**databaseURL 꼭 포함**)
5. 규칙(Rules) 탭에 아래처럼 입력 후 게시

```json
{
  "rules": {
    "teamMaker": { ".read": true, ".write": true },
    ".read": false, ".write": false
  }
}
```

6. 배포: 이 저장소 **Settings → Pages → Branch 선택 → Save** 하면 `https://<아이디>.github.io/team_maker/` 주소가 생겨요
   (Netlify Drop 등에 `index.html`만 올려도 돼요)
